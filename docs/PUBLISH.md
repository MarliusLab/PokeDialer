# Procedura di pubblicazione

La repository `MarliusLab/PokeDialer` è pubblica. Per ora contiene soltanto codice e istruzioni. La build APK completa, ROM e tracce audio originali non vengono pubblicate automaticamente.

Per una eventuale release pubblica verificare prima i diritti sui sorgenti originali, sulle grafiche, sul marchio Pokémon e sulla musica.

1. Eseguire il collaudo completo come indicato in `TEST_PLAN.md`.
2. Verificare gli hash e la firma del certificato Marlius.
3. Redigere note di versione che distinguano esplicitamente **verifiche statiche** da **test su dispositivi reali**.
4. Non committare mai file `.p12`, `.jks`, password, ROM o rapporti con dati personali.
5. Distribuire un pacchetto firmato soltanto dopo verifica dei diritti di distribuzione.
