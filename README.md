# PokeDialer

Versione Android personalizzata e offline del progetto PokeDialer.

## Versione

- Nome app e nome APK: **PokeDialer** / **PokeDialer.apk**
- Pacchetto Android: `com.ajamalen.pokedialer`
- Ultima versione di lavoro: **3.1.4**
- Android minimo dichiarato: 7.0 (API 24)
- Stato: collaudo sui dispositivi non ancora completato.

## Caratteristiche previste

- Catalogo esteso di Pokémon e allenatori
- Profili e personalizzazioni per contatto con salvataggio offline
- Musiche e temi grafici
- Diagnostica, statistiche e backup locali
- Popup iniziale con Red e Green, PNG trasparenti
